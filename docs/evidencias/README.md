# Evidencias de pruebas

Una carpeta por caso de prueba de la V10 (`PR-xx`, ver `docs/requisitos.md`). Cada carpeta contiene:

- `prueba.txt`: salida de `mix test` del caso (aprobadas y, si falla, esperado contra obtenido).
- `antes.txt` y `despues.txt`: datos consultados antes y después, cuando el caso cambia datos.
- `panel.png`: captura del detalle mostrado en el panel, cuando el caso llega al panel.
